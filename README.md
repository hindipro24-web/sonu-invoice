# Smart Parts Billing — Future UI

Deployment-ready static non-GST billing software with a futuristic SaaS interface.

## Included
- Responsive SaaS dashboard
- New invoice workflow with searchable 65-part master
- Quantity +/- and editable rate
- Custom parts and rate master
- Invoice history and payment status
- Customer list generated from saved invoices
- Business logo upload and PDF branding
- Settings, JSON backup/restore and local-first storage
- Professional A4 invoice PDF with fixed numeric alignment
- PDF preview, download and Android/Web Share support
- Installable PWA shell

## Intentionally not included
- No automation center
- No webhook / n8n / Make workflow
- No automatic WhatsApp messaging
- No cloud backend or API key requirement

## Deploy
Upload the root files to GitHub Pages, Netlify, Cloudflare Pages or any static host.
